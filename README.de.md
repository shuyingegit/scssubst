## Warum ScsSubst?

Tiefem Ordner einen Buchstaben geben — ohne Kopieren, wie lokale Festplatte.

Tools, die schreiben/löschen können — Angst vor Löschen außerhalb? Ein Laufwerk, das sie nicht verlässt.

<p align="center">
  <img src="docs/hero.png" alt="ScsSubst hero" width="920">
</p>

## Wofür es gut ist

- Häufige Ordner → Buchstaben
- Tools auf einem Laufwerk halten
- Lange Projektpfade kürzen
- Ein Laufwerk pro Arbeitsbereich

### Fokus: sichererer Sandbox-Arbeitsbereich

**Ein Laufwerk, das sie nicht verlässt**

Angst vor Übergriff? Ordner mappen und das Tool auf dem Laufwerk halten.

1. Dedizierten Arbeitsordner anlegen
2. Als Laufwerk mappen (z. B. Z:)
3. Tool-Workspace auf Z:

> Tool-Workspace auf diesem Laufwerk. Praktische Isolation, kein Kernel-Sandbox.

## Hauptfunktionen

Einfach, stabil, unkompliziert.

- **Ein-Klick-Einbindung** — Ordner und Laufwerksbuchstaben wählen, Verbinden — optional beim App-Start erneut einbinden.
- **Native Erfahrung** — Im Explorer wie ein normales Laufwerk — kürzere Pfade.
- **Autostart** — Gespeicherte Zuordnungen beim Öffnen von ScsSubst wiederherstellen.
- **Leichtgewichtig & stabil** — Nur Windows-APIs — kein Drittanbieter-Dateisystemtreiber. Kleines Portable-Build.
- **Mehrere Zuordnungen** — Mehrere Ordner-Zuordnungen, jeweils eigener Buchstabe.
- **Erweiterte Optionen** — Sichtbarkeit für erhöhte Apps, Papierkorb usw. Standard einfach.
- **Testversion nach Installation** — 7 Tage Test; danach Lizenz (Monat / Jahr / lebenslang).
- **Sandbox-Arbeitslaufwerk** — Schreibende Tools überschreiten oft Grenzen und löschen Falsches. Dedizierten Ordner als Laufwerk mappen und Tools darauf richten.

## FAQ

**Unterschied zum Cloud-Mount?**  
ScsSubst mappt Ordner auf dem PC. Für Cloud/WebDAV bitte ScsDriver (drive.scsoi.com).

**Was ist der Unterschied zwischen Test- und Vollversion?**  
Gleiche Funktionen. Die Testphase dauert 7 Tage; mit dem Code eines Freundes 14. Startet jemand die Testphase mit Ihrem Code, erhalten Sie ebenfalls +7 Tage, ohne Limit. Lebenslange Lizenzen nicht. Danach ist eine Lizenz nötig.

**Wie nutze ich ScsSubst als sichereren Sandbox-Arbeitsbereich?**  
Legen Sie einen dedizierten Arbeitsordner an, mappen Sie ihn auf einen Buchstaben und richten Sie den Tool-Workspace darauf. Fehl-Löschungen bleiben auf dem Laufwerk. Kein OS-Sandbox.
